# Ethics and safety

- Only made-up (synthetic) logs, plus public datasets whose licence allows reuse.
- No live AWS accounts, no scanning, and no attack tools run by this project.
- The tool is read-only: it never changes permissions, disables accounts or blocks activity.
- No real credentials or personal data may be committed. Sample key IDs are made up.
- An alert means "please review", never "attack confirmed".
