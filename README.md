# CloudTrace

Explainable detection of risky cloud account changes, built for the CyberFox Society
Cybersecurity Research & Development internship (Offer ID CF-RD-2026-054).

**Status:** work in progress. Uses only made-up (synthetic) logs. It never connects to AWS.

## Quick start
    py -3.13 -m venv .venv
    source .venv/Scripts/activate
    pip install -r requirements-dev.txt
    pytest -q

See ETHICS.md for the safety rules.
